# Design

InterviewAI uses an AI-native practice-studio visual system. The light lavender field reflects a student preparing in a familiar, low-pressure workspace; deep slate gives the active question enough gravity without turning the product into a test screen.

## Tokens

- Background: `#FAF5FF`; foreground: `#0F172A`; primary: `#7C3AED`; action accent: `#EC4899`.
- Headings use Lexend. Body copy uses Source Sans 3.
- Cards use 12–24px radii according to their prominence. Use either a subtle border or a shadow for elevation, not both.

## Interaction

- Strong pink action buttons begin a practice task; violet indicates selection, navigation, and feedback context.
- Controls have visible keyboard focus and 150–300ms color transitions.
- Avoid visual score pressure: feedback should identify an actionable improvement, never declare a student interview-ready or unready.

## Responsive behavior

- At desktop, the navigation rail remains alongside the practice workspace.
- At smaller sizes, navigation becomes a horizontal scrollable row and all content uses one column.
